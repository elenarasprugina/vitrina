# Месяцы как календарь (сделано 20.10.2026)

Её решения (20.10): новый месяц — с 1-го числа, но это настройка (потом, возможно, календарь 13 лун / Dreamspell); маршрут, перешедший через границу месяца (Белый Соединитель Миров 31.10–12.11), в новом месяце просто стоит первой карточкой — это содержимое, решает она сама в панели; заглушка — название месяца и крупное красивое «скоро».

## Как работает
- **Основной адрес** `13mirrors.ru/vitrina/` — месяц, который сейчас идёт (по Москве, с `startDay`-го числа), если он опубликован; если нет — последний опубликованный до него. Страница главного адреса испечена с `currentShowcase` на момент публикации; `M13.boot` сам переходит (`location.replace`) на `ГГГГ-ММ/`, когда по дате пора и тот месяц есть в `index.showcases` (#карточка сохраняется). Публикация и список «Витрины» тоже ставят `currentShowcase` по календарю (`monthAutoMain` в `admin.js`).
- **Стрелки** под названием месяца: «← прошлый опубликованный · следующий →»; если следующего нет — «Ноябрь · скоро →» на заглушку. В предпросмотре панели не уводят.
- **Заглушка** — страница `ГГГГ-ММ/` для месяца сразу после последнего опубликованного (`pageHTML('soon')`, `data-view="soon"`, `renderSoon` в `vitrina.js`). Фон, верхняя строка и низ — последнего опубликованного месяца; содержимого черновика нет. Опубликовала месяц — его страница заменяет заглушку, заглушка переезжает на следующий месяц.
- Выключить «по календарю» — как раньше: основной адрес ведёт на месяц с «Открывать по основному адресу».

## Модель данных
`settings.months = { auto (по умолч. да), cal: 'greg', startDay (1–28, по умолч. 1), arrows (по умолч. да), soon: { word ('скоро'), font, size: 'm'|'l'|'xl', color, note } }`.
Код: `M13.monthNow / monthPick / monthSoon / monthName`, `monthNavHTML`, `renderSoon` (vitrina.js); `monthsBlock`, `monthAutoMain` (admin.js). Панель: «Витрины» → «Месяцы как календарь».

## Проверка
`window.M13_TODAY='2026-11-01'` на главной — переход на `2026-11/`, если ноябрь опубликован.
