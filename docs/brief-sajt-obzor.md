# Бриф: как устроен сайт 13 MIRRORS (коротко, для соседних веток) · 06.11.2026

Для новой разработки (например, инструмент «Куб Метатрона»): общая картина, чтобы новое встроилось так же, как всё остальное. Подробности — в `elenarasprugina/vitrina`, `docs/status.md` (шпаргалка со ссылками на тематические файлы).

## Главное правило
**Всё настраивает она сама в панели** — кнопками, галочками, полями, загрузкой картинок. Код задаёт «как работает», а тексты, картинки, цвета, включено/выключено — это данные из панели. Новый инструмент делается так же: всё, что она может захотеть поменять, — поле в панели.

## Из чего состоит
- **Главная** `13mirrors.ru` — отдельный репозиторий `elenarasprugina.github.io` (дверь, логотип, Гримуар-заглушка, «Конфиденциальность»).
- **Витрина** `13mirrors.ru/vitrina/` — репозиторий `elenarasprugina/vitrina`. Месяцы как календарь (`2026-11/`…): фон месяца, карточки (раскрываются, на обороте — плашки, кнопки, вопрос дня, колесо кина), события, «Индивидуальная работа» с записью на встречи.
- **Маршруты по дням** (`routes/<имя>/`) — 13-дневные маршруты по волне Цолькина: Карта дня, сцена «Двери», калейдоскоп, Солнце финала, коды. Пример — Красный Небесный Странник.
- **Узоры** (`uzory/`) — короткие практики-сцены: «Сад» (хоровод 12 цветов, свой цветок) и **Костёр Самайна** (огонь по 13 тонам, листок желания сгорает, искры, знак тона, звук; вопрос и пожелание на каждый день волны).
- **Свой кин** (`kin/`) — колесо-сейф для даты рождения → кин, архетип, шестерёнки Цолькина и 3D-бублик.
- **Пространство 13 MIRRORS** (`prostranstvo/`) — живая комната-оранжерея (шаг 2 сделан 04.11), предметы = места сайта.
- **Отражения, Песочница, События, Оферта** — отдельные страницы витрины.
- **На хостинге Beget** (не GitHub): запись на встречи `zapis.13mirrors.ru`, бот-тесты ПсиПоинт, бот Host (Телеграм). Репозиторий `13mirrors-bot` (закрытый).

## Код
Чистые HTML/CSS/JS, **ES5, без библиотек и сборщиков**. У каждой части свой файл в `assets/`: `vitrina.js/css` (витрина), `route.js/css`, `doors.js/css`, `kaleido.js`, `sun.js` (маршруты), `uzory.js/css`, `koster.js/css` (узоры, костёр), `kin.js`, `kinwheel.js`, `kinmech.js` (кин), `space.js/css` (пространство). Тяжёлое грузится только там, где нужно. Рисование — canvas/SVG своими руками.

## Данные и панель
- **Панель** `vitrina/admin/` (`admin/admin.js`) — её рабочее место: разделы по частям сайта, предпросмотр («Посмотреть»), библиотека (архетипы, маршруты, Цолькин).
- **Черновик** живёт в её браузере → кнопка «Сохранить» кладёт его в закрытый репозиторий `13mirrors-content` → кнопка **«Опубликовать»** собирает сайт и кладёт в `vitrina/data/*.json` (+ картинки в `media/`). Публикует **только она сама**.
- Файлы данных: `settings.json`, `showcases/ГГГГ-ММ.json` (месяцы), `routes.json`, `journeys.json` (маршруты по дням), `uzory.json` (узоры и костёр), `reflection.json` (кин и отражения), `events.json`, `sandbox.json`, `formats.json`.
- Новое поле: значение по умолчанию в коде + поле в панели + перенос в её черновик (`migrate()` в `admin.js`, только в пустые поля — её правки не трогать).
- Картинки она загружает в панели (обрезка, «✎ Настроить» — кадр и свет); в черновике — ссылки `m13media:…`.
- Сайт: GitHub → автоматически копируется на хостинг Beget (`13mirrors.ru`). (С 02.11 Beget лежит после взлома.)

## Её правила (обязательно)
- Она психолог, **не программист**: объяснять просто, по-русски; показывать снимками (телефон 390 px и компьютер 1366–1440 px).
- «Обсуждаем» / «стоп» — ничего не менять; делать по «делаем».
- **Никакой аналитики, форм, внешних подключений** (шрифты свои, `assets/fonts/`; никаких CDN и Google Fonts).
- **Анонимность участников:** всё, что человек вводит, остаётся на его устройстве; если где-то нельзя — предупредить её.
- Не публиковать за неё, не создавать pull request; работа — в своей ветке, она вливает сама.
- В конце задачи — 2–4 строки в `docs/status.md` («Последние изменения») и ссылка, что влить.
