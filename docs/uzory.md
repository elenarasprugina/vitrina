# «Узоры» — образные опросники 13 MIRRORS (решения 21.10.2026, кода ещё нет)

Её две папки: «Мой цветок» (`cvetok_runner.py` + `moj_cvetok.json` + `kontakty_pomoshchi.json`) и «Образ · Свет в окне» (`obraz_runner.py` + `obraz_svet_v_okne.json`). Программки на Python только собирают итог из кусочков текста; сами тексты — в `.json`. **На 21.10 пришли только программки, `.json` она пришлёт** (без них не начинать: по ним строятся поля панели и импорт).

## Две среды
- **ПсиПоинт** — академическая среда, только валидированные опросники (HADS и т. п.), баллы и шкалы. **Остаётся только в Телеграме.** На сайте его раздела нет совсем — ни заглушки, ни «скоро». Если когда-нибудь — отдельная задача (видимый/невидимый, потом, может быть, «скоро»).
- **13 MIRRORS · «Узоры»** — образные (ассоциативные) опросники. Без баллов и «диагнозов», слово «тест» не используем: человек «входит в узор». Честная строчка вроде «Это не тест, а способ посмотреть на себя через образ».
- Общая «кухня» — только у неё: сервер Beget (`13mirrors-bot/psypoint`), вкладка результатов в панели рядом с HADS, с пометкой источника.

## Название и вход
- Раздел — **«Узоры»** (не «Калейдоскоп», не «Отражения» — путается с «Картой-Отражением»). Название и строчка-приглашение (предложено «Найди свой узор») **меняются в панели**.
- Вход — **карточка на витрине** → страница пространства (адрес предложен `…/vitrina/uzory/`), там узоры на выбор. Ссылка с главной 13mirrors.ru — туда же, в панели выключается. Именная ссылка ведёт сразу внутрь узора.

## Пространство узора (общая заготовка для всех узоров)
Пространство (фон + движение) → хоровод стеклянных карт → шаги-вопросы поверх того же пространства → итог → кнопки.
- **Карт всегда 12** (12 цветов / 12 образов), стеклянные, прозрачные, с бликом. Кружатся хороводом, как «бублик» волны.
- **В центре — светящаяся «дышащая» точка: это человек.** Касание → свет расходится кругом, хоровод оживает. Связка «я — центр»: тонкие светящиеся нити от точки к картам; выбранная карта плывёт в центр и сливается со светом.
- **Надпись у точки — НЕ «Встань в центр»** (её замечание: звучит командно). Мягкий вариант — выбрать ей (предложены: «Здесь — ты», «Коснись света», «Это твоё место», «Ты — в центре»); текст меняется в панели.
- Имя у точки — по желанию, вписывает сам; **остаётся только на его устройстве, к ней не уходит даже по именной ссылке**.
- Выбор: **«Наугад»** — матовое стекло, касание центра → хоровод замедляется, карта напротив проступает; **«В открытую»** — стекло проясняется, выбирает любую; **«Моего цветка здесь нет»** — назвать свой (в программке это `pick_mode` и `flower: own`).
- Живость (шаг 4): время суток (по часам человека, считается на устройстве, или постоянное из панели: утро/день/сумерки/ночь — цветом и свечением, без отдельных картинок); погода (штиль, ветерок, сильный ветер, дождь, туман, снег); лепестки, пыльца, бабочки, светлячки, снежинки; зима — свой набор 12 карт (снежные цветы) + иней. Звук — только по кнопке, выключен сначала. Идея: дыхание точки в ритме спокойного дыхания («дыши вместе со светом») — решает она. Кнопка «Остановить движение»; на слабом телефоне частиц меньше само.
- Картинок пока нет: она соберёт (промпты → генерация). До них — нарисованные заглушки. Вес — в основном картинки (≈2 МБ на узор после сжатия панелью); зимний набор грузится только зимой.

## Результат и кнопки
- Всё считается в браузере (программки переписать на ES5), тексты — в данных (черновик), правятся в панели. **Кнопка «Загрузить из файла»** — она загружает `.json` сама, всё раскладывается по полям.
- **С именной ссылкой:** «Сохранить себе» (копировать / скачать файл — на устройстве) + «Отправить проводнику» (сначала показываем, что уйдёт, человек подтверждает → Beget → ей уведомление в Телеграм «Мой цветок · код 7Q2M» → результат в панели под кодом).
- **Без ссылки:** пройти можно; «Сохранить себе» + **«Написать проводнику»** (копирует результат и открывает Телеграм к ней, как «Написать» на витрине, с меткой Host). На сервер ничего не уходит. Над кнопками её текст-приглашение («Если хочется обсудить — напиши мне»), меняется в панели.
- «Рефлексия» в «Цветке» (в программке — «для записи»): без ссылки никуда не уходит, человек видит подтверждение; по ссылке уходит только если он сам нажал «Отправить» и видел, что уходит.
- Телефоны помощи (`kontakty_pomoshchi.json`) — показываются всегда.

## Именные ссылки
- Панель → «Приглашения» → выбрать узор → «Создать ссылку» (копируется сама) → вставить человеку в Телеграм. Вид: `…/uzory/cvetok/?k=7Q2M`.
- На сервере — только код и ответы, **без имён**. Одна ссылка — одна отправка; неиспользованная сгорает через 30 дней (срок меняется). Автоудаление результатов — 30 дней (предложено, ждёт её «да»).
- Пометка к ссылке — поле **«Для себя»** (не «кому дала»; не «метка» — так зовутся метки Host): **только в её браузере**, на сервер не уходит; есть «Скачать список приглашений» (на случай другого компьютера / очистки браузера).
- ⚠️ Страница «Конфиденциальность» (`elenarasprugina.github.io`): дописать — сайт обращается к её серверу Beget только по кнопке «Отправить проводнику», что уходит, когда удаляется.

## Порядок работы (каждый шаг — свой чат, по её «делаем»)
1. **Проба пространства «Мой цветок»** — точка в центре, хоровод 12 стеклянных карт, наугад / в открытую, ветерок; заглушки вместо картинок; отдельной страничкой без вопросов и панели.
2. Вопросы и итог, «Сохранить себе» / «Написать проводнику», раздел «Узоры» в панели, «Загрузить из файла».
3. Именные ссылки, отправка на Beget (`13mirrors-bot`), уведомление в Телеграм, «Конфиденциальность».
4. Живость: время суток, погода, бабочки, зима.
Потом «Образ · Свет в окне» — по той же заготовке (одна из 12 карт хоровода «Образов»), в основном её тексты и картинки.

**Ждёт её:** `.json`-файлы; выбрать мягкую надпись у точки; «Узоры» или «Твои узоры» (рекомендация — «Узоры» + приглашение «Найди свой узор»); срок хранения 30 дней.
