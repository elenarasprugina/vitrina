# Страницы маршрутов по дням — как устроены (итог на 04.10.2026)

Итог того, что сделано для «Жёлтого Солнца». Как к этому пришли — `docs/yellow-sun.md` (п. 1–32, история; п. 14 — главная конструкция). План, как быстро собирать следующие маршруты, — `docs/konstruktor.md`.

## Файлы
- Страница: `routes/<id>/index.html`. Сейчас одна: `routes/yellow-sun/` (`<div id="ys" data-base="../../" data-route="yellow-sun">`, `M13R.boot()`). Внутри — og-теги для превью ссылки (заданы вручную) и номер версии `window.M13RV` (поднимать при каждой правке кода маршрута).
- Код (общий для всех маршрутов): `assets/route.js` (`window.M13R`), `assets/route.css`, `assets/kaleido.js` (`M13K` — калейдоскоп, стёклышки, камни), `assets/sun.js` (`M13S` — Солнце финала).
- Данные: `data/journeys.json` = `{ items: [маршрут] }`; страница ищет маршрут по `data-route`. Черновик — в `13mirrors-content` той же структуры. Ключи в черновике — `_keys` (сами слова), на сайте — только отпечатки `keys` (SHA-1 от `m13|<id>|ключ`).
- Пробные страницы (не для участников): `routes/yellow-sun/kaleido.html`, `final-lab.html`, `sun-lab.html`.
- Панель: раздел «Страницы маршрутов» (`viewJourneys`, `jRoute` в `admin/admin.js`); вкладки — Основное · Кирпичи на спирали · Растения · Карта дня · 13 дней · Колода · Диск · Личная карта · Калейдоскоп и состояния · Стёклышки · Финал · Код участника. Выбор маршрута появляется, когда их больше одного. **Кнопки «Новый маршрут» пока нет.**

## Модель данных маршрута (главное)
- `id`, `routeId` (связь с карточкой витрины, `data/routes.json`), `title`, `path`, `start` (ГГГГ-ММ-ДД; 13 дней подряд, смена дня в 00:00 МСК).
- Спираль: `masterDesktop` (16:9), `masterMobile` (9:16), `dimTop` (приглушить свет сверху), `zones.desktop / zones.mobile` (камни дней 1–12 и центр 13 по картинке — размечаются в панели), `glow` (свет камней), `stage`, `neon`, `plants` (светящиеся растения).
- Вход: `keys` (Путешествие / Погружение), `trace` (ссылки «Оставить след»), `texts` (все надписи страницы; пусто — заготовка в коде).
- `dayCard.blocks`, `personalCard.blocks` — карты из блоков (вид, «кому видно» по форматам, выравнивание). Текст дня — `days[i].texts[id блока]`.
- `days[13]`: `n, kin, kinName, seal, tone, image, glowColor, texts {focusTitle, focus, mainQuestion, personalQuestion, personalPractice, closingPoint, diskQuestion}, cardOperation, environment`.
- `deck`: 13 карт `{id, quality, axis, less{rim, spoke}, more{spoke, rim}, recognize{6 зон}, road{6 зон}, способ}`, рубашка, `disk` (картинка/видео, овал, 6 зон касания, свет, названия зон).
- `states.items` — 12 состояний (3 на входе, до 3 на выходе); `kaleido` (стиль узора); `glass` (вид стёклышек дней, состояний, подарков); `final` (блоки Карты дня 13, Солнце, сохранение картинки/PDF, отзыв, музыка, логотип).

## Путь участника (кратко)
Наблюдение — без кода: спираль → камень дня → Карта дня. Путешествие / Погружение — ключ от неё → 3 состояния → калейдоскоп складывает узор → **личный код** (в нём формат, перемешанная колода и состояния; сервера нет, всё на устройстве) → каждый день: камень → Карта дня → карта из колоды вслепую → личная карта (диск: «Узнаю себя, если…», «Здесь», дорога в центр) → стёклышко дня в узор. Слово-подарок (`ДАР-…`) — бонусное стёклышко от неё. День 13 — урезанная Карта дня, «С чем вы выходите?», «Собрать маршрут» → финал: свет по спирали, луч, Солнце из стёклышек человека → «Сохранить моё Солнце» (картинка, PDF для раскрашивания), «Оставить отзыв».
Анонимность: ничего не отправляется; код и стёклышки только у человека.

## Как сейчас сделать новый маршрут (вручную, без конструктора)
1. Скопировать `routes/yellow-sun/index.html` → `routes/<новый id>/index.html`: поменять `data-route`, заголовок, og-теги, картинку превью.
2. В `data/journeys.json` (и в её черновик — через `migrate` или её руками) добавить маршрут: копия Жёлтого Солнца с новыми `id`, `start`, `title`; очистить тексты дней и колоды; новые `kin/kinName/seal/tone` для 13 дней.
3. Она: картинки спирали → разметка камней в панели → тексты дней, колода, диск → ключи → публикация; на витрине — карточка маршрута со ссылками на `routes/<id>/?mode=…`.
4. Проверка — `?debug=1` (каждый день, финал, коды), телефон и компьютер.
Узкие места: шаги 1–2 делает Claude; надписи по умолчанию в `route.js` местами говорят «Солнце» (финал, стёклышки) — для другого маршрута их надо задать в панели или сделать название финала настройкой; перенос её текстов из документа — вручную.
