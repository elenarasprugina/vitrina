Собрано из `vitrina/docs/zapis.md`, `docs/host-labels.md`, `docs/psypoint-anketa.md` и `13mirrors-bot/zapis/README.md`, `13mirrors-bot/psypoint/README.md`.
Подробности — там; здесь только то, что нужно, чтобы связать расписание сайта с Компасом.

## Общая картина
```
Витрина 13mirrors.ru (GitHub → копия на Beget)
   │  окошко записи на плашках «Индивидуальной работы»
   ▼
Программа записи  zapis.13mirrors.ru  (Beget, PHP + SQLite)   ← ЮKassa (оплата)
   │  после записи кнопка «Написать» →
   ▼
Бот Host  @thirteenmirrors_host_bot  host.13mirrors.ru  (Beget, один index.php)
Бот ПсиПоинт  psypoint.13mirrors.ru  (Beget, PHP + SQLite)  → результаты тестов/анкет → Компас (план)
Компас БФО — её приложение, где она записывает клиентов (в основном из фонда, без оплаты)
```
Все три программы живут на Beget. Домен 13mirrors.ru и поддомены `zapis`, `psypoint`, `host` — на REG.RU (DNS там), Beget их не держит.
⚠️ **Ноябрь 2026:** Beget взломан 02.11, хостинг восстанавливают (обещают почти 100 % сайтов). Пока он лежит, запись, оба бота и панели «Запись»/«ПсиПоинт» не работают.

## 1. Запись на сайте (сделано 28–29.10, шаги 1–3 из 5)
**Как видит человек:** карточка «Индивидуальная работа» → плашка (встреча 90 мин, шаманская 60, расстановки 60, регрессия 180, знакомство 20 — без цены) → «Записаться» → календарь со свободными днями → время (по Москве) → онлайн / очно (если включено) → «Оплатить» (ЮKassa; время держится ~15 мин) или «Записаться» (встреча без цены — сразу) → «Вы записаны», «Добавить в мой календарь» (Google / файл .ics — на телефоне человека) и «Написать» (бот Host с меткой встречи).

**Что хранит сервер (анонимно):** только занятое время — номер `Z-XXXXXX`, день, начало–конец (минуты по Москве), статус, вид встречи, онлайн/очно, цена, её пометка. **Ни имени, ни телефона, ни почты.** Статусы: `hold` (на оплате), `paid` (оплачено), `booked` (без оплаты), `block` (закрыла она сама; у `block` бывает «очно» — с дорогой). Прошедшее старше 90 дней стирается.

**Свободное время** = рабочие часы по дням недели − выходные/отпуск − занятое (с перерывом до и после). Настраивается в панели («Запись»): часы, перерыв, шаг начала, «не позже чем за N часов», «на N дней вперёд», отмена за N часов, очные встречи (дорога 60 мин, не больше 2 очных в день, в любые дни или выбранные даты), «без оплаты — не больше N записей в день» (2).

**Фонд сейчас:** клиенты фонда через сайт не записываются. Она **закрывает время сама** в панели: «Записи» → «Закрыть время» → «Очно (учесть дорогу)» → в списке «Закрыто вами · очно · фонд». Это единственная связь расписания фонда с сайтом сегодня — **ручная**.

**Входы программы (для того, кто будет связывать):**
- `GET zapis.13mirrors.ru/index.php?a=free&s=<ключ встречи>&m=online|offline` — свободное время по дням (без пароля).
- `POST panel.php` `{p, action}` — с паролем, только с адресов витрины: `get` (настройки и записи), `block` (`day, from, to, note, offline` — закрыть время), `release` (`code` — освободить), `save`, `free`.
- Записи можно читать и закрывать время **только через `panel.php` с паролем**. Отдельной ленты календаря (.ics) у программы записи **пока нет**.

**Календарь Google — шаг 4, НЕ сделан** (решения 28.10):
- Записи сайт кладёт в рабочий календарь `13mirrors.host@gmail.com` (своим цветом; он добавлен в её Бизнес-календарь). Доступ она даёт сама кнопкой «Разрешить», пароль не нужен.
- Из личного календаря сайт видит **только «занято / свободно»**.
- Можно закрыть время событием «занята» в рабочем календаре.
- Свободное = рабочие часы − записи − «занято» из календарей. Список записей — главный у сервера (не у Google), чтобы не было накладок. Связь с Google прервалась → сайт перестаёт предлагать время («Запись временно через сообщение»), бот сообщает ей.

## 2. Бот Host — `@thirteenmirrors_host_bot`
- Где: `host.13mirrors.ru`, **один файл `index.php` только на Beget**. ⚠️ Копии кода в GitHub нет (ключ бота вписан прямо в файл) — когда Beget вернётся, сохранить файл себе и сменить ключ бота.
- Как сайт с ним связан: любая кнопка «Написать» / «Задать вопрос» ведёт на `t.me/thirteenmirrors_host_bot?start=<метка>`. Метка говорит, откуда человек: маршрут и формат (`blue_hand_journey`, `red_skywalker_question` — таблица в `docs/host-labels.md`) или встреча после записи (метка плашки, например `intro_meeting_20`). **О человеке сайт ничего не передаёт**; имя/ник она узнаёт, только если он сам напишет.
- Чего бот пока **не умеет** (шаг 5 записи, не сделан): сам сообщать «Новая запись: …, оплачено», утром «Сегодня у вас: …», тревога при сбое календаря/ЮKassa. Программа записи боту пока ничего не шлёт.

## 3. Бот ПсиПоинт — тесты и анкеты
- Где: `psypoint.13mirrors.ru` (Beget, PHP); Телеграм сам присылает сообщения боту.
- Что делает: тесты с баллами (HADS) и анкеты перед встречей без баллов (анкета для подростков, `?start=teen`). Ей в Телеграм — «Новая анкета от @ник». Тексты анкет она правит в панели («ПсиПоинт» → «Анкеты»).
- Что хранит (`psypoint.db`, только Beget, Россия): код результата (`HADS-…`, `ANK-…`), тест, **ник, id и имя из Телеграма**, баллы, ответы, когда пройден, `taken_at` — когда забрал Компас. Удаляется только старше 30 дней **и** уже забранное Компасом. Здесь человек не анонимен — это её решение (работа с человеком).
- Связь с Компасом — **план, не сделано**: в Компасе кнопка «Забрать результаты» → результаты подставляются клиенту по нику в Телеграме, остальные — «Не привязаны». У ПсиПоинта уже есть вход `panel.php` (пароль) с действием `results`; отдельного входа «для Компаса» и отметки «забрано» пока нет.

## 4. Что нужно решить для связки с Компасом
Узнать про Компас БФО:
1. Умеет ли он синхронизироваться с Google Календарём (или выдавать/читать ссылку-подписку .ics)? Есть ли у него API?
2. Где он хранит данные (Россия? облако?) и кто к ним имеет доступ — в нём имена клиентов фонда.

Варианты (по убыванию простоты):
- **А. Через Google Календарь (шаг 4 записи).** Компас пишет встречи в календарь Google → сайт видит там «занято» (без имён) и не предлагает это время; записи с сайта появляются в календаре `13mirrors.host` → она видит их в Бизнес-календаре и при желании переносит в Компас. Сайт не получает ничего, кроме «занято с … до …».
- **Б. Лента .ics от программы записи.** Добавить в `zapis` закрытую ссылку-подписку (длинный секретный адрес) со всеми записями сайта (вид встречи, время, номер — без имён) → Компас или любой календарь подписывается. И наоборот: программа записи читает ленту .ics из Компаса и считает её «занято».
- **В. Как сейчас — вручную:** фонд записывается в Компасе, она закрывает это время в панели «Запись» → «Закрыть время» (очно — с дорогой).

**Анонимность (её правило):** к сайту и в программу записи из Компаса должно уходить только «занято с … до …» (и, может быть, «очно»), **без имён и названий фонда**. Если какой-то вариант потребует передавать имена — предупредить её.
