# Ближайшее событие на лицевой стороне карточки (сделано 20.10.2026)

Её решение 20.10: пустые (стеклянные) карточки витрины заполняются картинкой ближайшего события из раздела «События».
Сразу как она поставила событие (с датой впереди и главной картинкой) — оно на карточке. Нажатие — как всегда: карточка увеличивается, потом оборот.
Подходит любой карточке.

## Как выглядит (её выбор из 4 проб: А арка, Б краешек карты, В тает, Г стекло)
- **Картинка тает** (`melt`) — снизу картинка события, растворяется вверх к надписям; подпись «дата · название» над кнопкой «открыть».
- **Матовое стекло с прорезью** (`frost`) — вся карточка размытой картинкой, чёткая только полоса (20 % высоты) с тонкими линиями цветом акцента; подпись под полосой.
- На увеличенной карточке — то же, крупнее. У маршрута, у которого на увеличенной карточке карта дня / живая обложка / финальный ролик, событие там не показывается (на маленькой — да).

## Модель данных
`card.front.ev = { on, src, ids, look, h, at, y, cap }`
- `src`: `'all'` (по умолч.) | тип события (`meeting`, `meditation`, `festival`, `trip`, `practice`, `other`) | `'pick'` — из `ids` (выбранные события).
- `look`: `'melt'` (по умолч.) | `'frost'`.
- `h` — высота «тает», % карточки (25–85, 60); `at` — где прорезь, % сверху (15–70, 48); `y` — какая часть картинки видна, % сверху (0–100, 50).
- `cap`: `''` — дата и название | `'date'` | `'none'`.
- Выключено (`on: false`) — на сайт не уходит (`cleanDeep` в `admin.js`).

## Какое событие
`evNear(c)` в `assets/vitrina.js`: из `evList('soon')` (видимое, не «пример практики», не закончилось — по `dateEnd`/`date`; без даты — в конце), с `cover`, подходит по `src`; первое по дате. Дата сегодня — `today()` (часы устройства; `window.M13_TODAY` для проб).
Рисует `evPeekHTML(c)` — слой `.m13-lay.m13-evp` под надписями (карточке добавляется `m13-deco`, надписи над слоем); стили — `vitrina.css`, раздел «Ближайшее событие».
`M13.evNear(c, data)` — для панели.

## Панель
Витрины → месяц → карточка → «Лицевая сторона» → «Показывать ближайшее событие» (`evFields` в `admin.js`): какие события, вид, ползунки, подпись; строка «Сейчас на карточке: …». В сетке карточек — метка «событие» / «событие: нет».
В «События» → «Главная картинка» — подсказка, что она же идёт на карточки.
