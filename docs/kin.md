# «Узнать свой кин» и базовые архетипы — решения и сделано 19.10.2026

## Главное
13 MIRRORS — про архетип, не про кин. Кин на сайте — **ключ**, а не описание: описаний кинов, печатей и тонов нет (они есть на других сайтах), внешних ссылок нет.
**Личный архетип** (Карта-Отражение, страница примеров `reflection/`) по кину **не показываем никому** — он индивидуальный, по ответам человека.

## Где (вариант В)
1. **Блок оборота «Узнать свой кин»** — новый вид блока карточки (ставит она в панели; сейчас — на «Карту-Отражение»): дата рождения → Kin N, цвет, знак печати, имя (цвет + тон + печать), базовый архетип печати (если отмечен) → кнопка «Подробнее» на страницу и «Заказать Карту-Отражение».
2. **Страница `vitrina/kin/`** (как Песочница, «← К витрине»), постоянный адрес для Telegram. То же + строки «когда»:
   - **тон**: «ваш тон — N, в каждой волне ваш день — N-й»;
   - **галактический день рождения** — ближайшая дата того же кина (раз в 260 дней);
   - **печать в маршруте** — маршруты идут 13-дневными волнами Dreamspell подряд, поэтому волна **считается** (не берётся из данных): ближайшие 2 волны, где печать встретится (день N, дата), даты волны, название — по первому дню волны (так называются её маршруты), а если в «Маршрутах» есть маршрут с той же датой начала — его название. Маршрут на витрине — «Открыть маршрут» (карточка); нет — «Информация о маршруте скоро появится» + «Узнать подробнее» (окно «Написать» с готовым текстом).
3. Тексты всех строк — в панели, с подстановкой ({кин}, {тон}, {день}, {дата}, {маршрут}).

## Базовый архетип печати на сайте
Из вкладки «Архетипы» Библиотеки: **только если у архетипа галочка «Показать на сайте»** — «Базовый архетип вашей печати в 13 MIRRORS — **название**» + **строка сути** (Classic). Статус не важен (её ответ: «Великая Мать» на пересмотре — тоже можно, суть есть). Нет галочки / не готов — «Архетип вашей печати ещё раскрывается в 13 MIRRORS» + приглашение в Карту-Отражение. Публикация кладёт на сайт только эти два поля отмеченных архетипов — остальная Библиотека на сайт не попадает.

## Сделано 19.10 (ветка `claude/happy-noether-bhgas0`)
- **Витрина** (`assets/vitrina.js`, раздел «СВОЙ КИН»; стили — конец `vitrina.css`, `.m13-kin…`): блок оборота `kind: 'kin'` (`title` — заголовок над полем), страница — вид `kin` (отдельная `vitrina/kin/` и внутренняя `#m13-int-kin` в витрине, «Подробнее» передаёт дату в памяти — `S.kinPre`, не в адрес). `assets/kin.js` грузится по требованию (`needKin`). Поле «ДД.ММ.ГГГГ» (точки сами), 29.02 — кнопки до/после полудня/не знаю (оба кина). Знак печати — `reflection.kin.sealImg[1…20]` или кружок цвета печати с номером; знак тона — точки и черты майя (SVG в коде). Волны — `kinWaves(печать, 2)`; «Открыть маршрут» — карточка текущей витрины (`kinCards` кладёт публикация на страницу kin/).
- **Данные:** `reflection.kin` = тексты (пусто — `M13.KIN_T`: label, ph, go, note, bad, hunab, noonBefore/After/Both, ifBefore/After, archOn ({архетип}), archOff, archNote, more, eyebrow, title, intro, toneH/T ({тон}, {номер тона}), birthH/T ({дата}), birthToday, routeH/T ({маршрут}, {даты}, {день}, {дата}), routeSoon, routeOpen, routeAsk, routeMsg) + `sealImg` + `arch` { печать: { name, essence } } — пишет только Библиотека (`libArchSite`).
- **Панель:** блок оборота «Узнать свой кин»; «Карты-Отражения» → «Узнать свой кин — страница и тексты» (все тексты, знаки печатей, какие архетипы на сайте, «Посмотреть страницу кина»); предпросмотр — кнопка «Свой кин»; публикация пишет `kin/index.html`.
- **Библиотека → «Архетипы»** (`libArchTab`, `libArchPage`, `LIB.parts.archetypes`, файл `library/archetypes.json`): 20 печатей, страница архетипа (Classic / Classic+, статус, «статус словами», рабочие слои, «Показать на сайте»); со страницы кина в Цолькине — «Базовый архетип печати». Загрузка — «Файлы» → JSON `{ app: '13mirrors-archetypes', items: [...] }` (её таблица переведена в такой файл: ИМИШ «Великая Мать» — на пересмотре, ИК «Дыхание Жизни» — утверждено); галочки «Показать на сайте» при повторной загрузке не сбрасываются. Таблицу Excel панель не читает — новые версии таблицы переводит Claude.

## Колесо даты — разговор и проба 19.10 (ветка `claude/beautiful-meitner-ozr2yg`, код сайта не менялся)
**Проба:** https://claude.ai/artifact/Rj894Jut2HFF16iBVbzMoc · исходник `docs/kin-koleso-proba.tpl.html` (вместо строки `<!--KINJS-->` — `assets/kin.js`: `sed '/<!--KINJS-->/{r assets/kin.js` + `d}'`).
**Её решения (ждут её «да» по пробе, потом — на сайт вместо поля даты):**
- Три кольца: снаружи **годы с 1950 по нынешний** (конец сдвигается сам каждый год; десятилетия подписаны), дальше **месяцы**, внутри **дни** (лишние в коротком месяце гаснут). 88 / 78 черточек обсуждали — она выбрала 1950.
- Выбор — **провести пальцем по кольцу**, на каждом делении **щелчок**: тихий звук (Web Audio, без файлов), вибрация (только Android — iPhone сайтам не даёт), «прыжок» метки. Кнопка **🔊/🔇** — выключает только звук; «выкл» помнит само устройство.
- Под колесом строка **«Ввести дату цифрами»** — для всех, кому так удобнее (и для родившихся до 1950).
- В середине колеса — тонкое **кольцо 260 точек** (20 волн по 13, цвет печати), мерцает. Дата выбрана → кольца даты растворяются, **те же 260 точек перелетают** в большой Цолькин, кин человека светится.
- Вид Цолькина — **выбирает она в панели**: волны лучами (по умолчанию) / спираль / таблица кругом (20 лучей-печатей × 13 кругов-столбцов); галочка **«Отмечать 52 портала»** (порталы постоянные, без описаний). Нужны ли переключатели участнику — не решено.
- 29.02 — как раньше (до/после полудня/не знаю).

### Проба, заход 2 (19.10, её правки по первой пробе) — та же ссылка
- **Колесо-сейф:** наверху неподвижное окошко со стрелкой, **кольцо поворачивается под пальцем** (с инерцией, доводится точно на деление); нажатие на число — кольцо само подвозит его под стрелку. Объёмные кольца-ступеньки (тень, фаска, неподвижный блик точёного металла, насечки по краю кольца лет), утопленная середина.
- **Материалы** (на сайте — выбор в панели): бронза / старое золото / лунное серебро / ночное стекло. Она хочет посмотреть все — выбор за ней.
- **Щелчки** (Web Audio, без файлов): сейф / дерево / мягкий; на десятилетиях, январе и 1-м числе — тяжелее. Вибрация на Android.
- **Без автосворачивания:** в середине дата словами + кнопка «Открыть» (звук замка сейфа); «← Изменить дату» возвращает колесо с той же датой.
- Кольцо 260 точек в середине мерцает и медленно идёт против часовой — ей нравится, оставляем. Любимый вид — «волны лучами» («цветочек»).
- **После «Открыть»:** любую точку можно нажать → карточка: Kin, имя, печать/тон/портал, ближайший день этого кина, волна (название по первому дню, даты, день N из 13); подсвечена его волна; «↩ К моему кину». Под Цолькином — тон, галактический день рождения, печать в двух ближайших волнах (тексты — как `M13.KIN_T` на сайте); ближайшая волна с её печатью обведена золотом, нажатие на строку волны показывает её на Цолькине.
- **Правки 19.10 (её отзыв):** у «Открыть» убран шум («пыл»), три звука на выбор — «Замок и звон» / «Поющая чаша» / «Перелив 13 колокольчиков» (пентатоника снизу вверх); нажатие на кин в Цолькине — тихое стеклянное «тинь» вместо щелчка сейфа, ловится точка в радиусе 16 px (было 22 — цепляло соседей), промах — тишина.
