# Запись Летописи: общий формат для всех опросников

Одна запись равна одному прохождению одного опросника. Один формат для «Как звучим вместе», «Образа», «Моего цветка» и всех следующих (в том числе АХАЦ, если его захотят привести к общему виду). Пример: `zapis_primer.json`.

## Кнопки в конце результата
- **Сохранить себе**: человек скачивает файл записи (или картинку-карточку) на своё устройство.
- **Отправить проводнику**: запись уходит тем же путём, что в АХАЦ. Над кнопкой одна строка: «Уйдут ваши ответы и карточка».
- **Записать в Летопись**: запись остаётся в Летописи на устройстве человека. Серверу она не нужна.

## Поля записи
| Поле | Что это |
|---|---|
| `schema` | Версия формата записи, сейчас `letopis-record/1` |
| `record_id` | Уникальный идентификатор записи |
| `created_at` | Дата и время прохождения, с часовым поясом |
| `questionnaire` | `id`, `version` и `title` опросника, из JSON опросника |
| `alias` | Как к человеку обращаться (необязательное поле, может быть пустым) |
| `guide_ref` | Если человек пришёл по ссылке проводника, её метка, иначе `null` |
| `answers` | Список ответов по шагам (ниже) |
| `result` | Что человек увидел: заголовок, строки, раскрытие, вопрос с собой |
| `reflection` | Слова человека из последнего поля, или `null` |
| `meta` | Служебное: режим выбора, взгляд изнутри или со стороны, выбранный цветок |
| `sent` | Отправлено ли проводнику и когда |

## Запись ответа в `answers`
Для каждого шага опросника, где человек мог что-то выбрать или написать:
- `step`: id шага
- `question`: текст вопроса **как его видел человек**
- `skipped`: `true`, если шаг пропущен
- `answer_id` и `answer_label`: выбранный вариант (id и подпись)
- `text`: собственные слова, если было своё
- для таблицы («лампочки» в цветке) `answer` содержит ответ по каждой строке

## Зачем хранить вопрос и подпись, а не только id
Тексты опросников будут редактироваться. Если в записи лежат только id, то через месяц запись прочитается другими словами, чем человек видел. Поэтому в записи всегда лежат текст вопроса и подпись ответа на момент прохождения.

## Правила
- Пропущенный шаг записывается с `skipped: true`, а не удаляется. В просмотре он показывается нейтрально.
- `reflection` и все `text` хранятся как написал человек, без обработки.
- Запись должна открываться без доступа к JSON опросника.
