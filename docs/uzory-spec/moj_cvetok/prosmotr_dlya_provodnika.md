# Страница просмотра для проводника

Страница, где ты открываешь записи, которые люди отправили кнопкой «Отправить проводнику». Работает для всех опросников, потому что формат записи общий (см. `zapis_letopisi.md`).

## Версия 1 (достаточно для начала)
1. **Список записей.** Строка: дата, имя (`alias`), название опросника. Сверху новые. Поиск по имени и фильтр по опроснику.
2. **Открытая запись.**
   - Сверху карточка результата: заголовок и строки, как их видел человек.
   - Ниже ответы построчно «вопрос — ответ». Собственные слова человека выделены. Пропущенные шаги написаны нейтрально: «не отвечал(а)», без красного и без значков.
   - Внизу поле `reflection` (последнее поле «что ещё хочется сказать»), отдельным блоком.
3. **Кнопка «Скопировать текстом»** для переноса в протокол: имя, дата, опросник, ответы, карточка, слова человека.
4. **Поле «Заметка проводника».** Пишет только проводник, человек её не видит.

## Версия 2 (когда накопятся записи)
- **Сравнение двух записей рядом.** Для «Моего цветка» это самое ценное: цветок, место, «хватает», слова цветка в двух датах. Различия подсвечены мягко.
- Экспорт записи в PDF.
- Группировка записей по человеку, если имя совпадает.

## Правила показа
- Ничего не оцениваем и не раскрашиваем: «мало», «слишком много» и пропуски выглядят так же, как «хватает».
- Не вычисляем «баллов» и «профилей».
- Имя не обязательно, без имени запись называется «без имени» с датой.
