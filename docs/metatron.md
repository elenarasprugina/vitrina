## Новый облик — «космическое поле» (решено 06.11, кода нет)
Деревянная шкатулка ей не нравится: «как игра», «карточки», «мёртвое».
- Весь экран — космос. Панели — один тихий значок в углу (настройки, звук, экспорт). Сетка в центре светится и дышит.
- Стекло и свечение, не акварель: прозрачное, тонкие края со свечением наружу, свет изнутри предметов, один золотой акцент на выбранном. Атмосфера, а не надписи по углам.
- Диск вместо шкатулки (склоняемся к полудиску внизу, под большой палец): крутится по инерции, защёлкивается на секторах со звуком. Внешнее кольцо — отделения (кристаллы, камни, формы, бусины, природа, ритуал) своим свечением, без надписей-кнопок; внутреннее — предметы в стеклянных капсулах, выбранный — золото.
- Тела = стихии, светятся изнутри, на орбите вокруг сетки: тетраэдр — огонь (рыже-оранжевый, угли, искры), октаэдр — воздух (прозрачно-белый, туман), икосаэдр — вода (голубой, перетекающий свет), куб — земля (зелёный, нефрит/малахит), додекаэдр — эфир (фиолетово-звёздный). Касание раскрывает карточку.
- Жесты: достать предмет из диска, бросить (летит и ложится в точку со следом), смахнуть за край — убрать, нарисовать пальцем спираль/круг — предметы разлетаются узором, двумя пальцами — вращать. Ноутбук: тачпад двумя пальцами — вращение, щипок — зум. Жесты через камеру — позже.
- **Дизайн сначала обсуждать с ней.** Начать с пробы: одно тело-стихия + полудиск + бросок камня, снимки 390 px и 1440 px.

## Заходы
**1. Движок** (не зависит от облика)
1. Круги садятся на вершины выбранного тела (сейчас совпадают только куб и октаэдр). Перспективу ослабить или переключатель «с перспективой / без».
2. Вращение: кнопка «вкл/выкл»; взяла рукой — автоповорот останавливается; двойное касание — сброс вида.
3. Скорость прорисовки: Медленно (~1 мин, по умолчанию) / Спокойно (~35 с) / Быстро + пауза.
4. Звук: одна долгая нота на семейство линий (≈8 нот), «зал», нарастающий тихий аккорд-подложка. Не «булькать».

**2. Тексты** (черновик — Claude, правит она; все — поля в панели)
5. Карточка тела-стихии: стихия, смысл, для каких намерений, сочетание с камнями, где в природе; чакры мягко («в традиции принято»). Тон: смысл + практика.
6. Карточки камней.

**3. Облик** — раздел «космическое поле» целиком; тела на сцене (не отдельной вкладкой), диск, режим созерцания (весь экран). Предметы «природы» выглядят дёшево — нужен другой уровень.

**4. Для людей**
7. Пошаговый проход для клиентов (это и есть «Окно»).
8. Видео прорисовки со звуком (webm/mp4) для сайта и сторис.
9. Дневник намерения — возможно, это «Куб волны».
