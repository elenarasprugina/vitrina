## 2. Прохождение дня (её блок, приоритет)
- **Наблюдение** — без кода. **Путешествие** и **Погружение** — по личному коду (п. 3). После входа все три видят одну и ту же спираль.
- Нажал светящийся кирпич дня → световой импульс по спирали к центру → из центра появляется **Карта дня** (общая для всех): номер дня, Kin, Dreamspell-печать, тон, «Фокус дня», **Главный вопрос** (`mainQuestion`, общий, из Kin) + картинка (есть всегда).
- Внизу Карты дня — **кнопка-спираль** (без подписи, светящийся знак спирали):
  - observation → назад на спираль (день Наблюдателя на этом закончен; практики у него нет);
  - journey / immersion → пространство выбора **карты-разрешения** (`permissionCard`; слово «печать» — только для Dreamspell).
- Выбор: закрытые карты **лучами по кругу, без центра**; в 1-й день 12, дальше на одну меньше (в 12-й — одна). Нажал карту → переворот (например «МНЕ МОЖНО ЗЛИТЬСЯ») = выбор окончателен → кнопка «Открыть» → полноэкранная **личная карта** (на телефоне — свой экран с прокруткой); в этот момент день `completed`.
- Личная карта: разрешение; строка «День 6 · Красный Ритмический Змей»; `personalQuestion`; `personalPractice`; `closingPoint` — всё **собирается по шаблонам дня** с подстановкой словоформ карты (не 144 текста: 12 карт + 13 дней с шаблонами). `mainQuestion` и `personalQuestion` — разные сущности, не объединять.
- Внизу личной карты: «Оставить след» (journey → группа Telegram, immersion → лично Проводнику) и кнопка-спираль (назад). Кнопки «Завершить день» нет. После возврата — без новой анимации.
- До 00:00 по сегодняшнему кирпичу снова открывается **та же** карта (новой выбор нет); после 00:00 — закрыта навсегда. Прошлые карты не открываются.
- День 13 (центр): Карта дня 13 общая; кнопка-спираль → финал Солнца — **пока заглушка** (`finalSunLayer`, заменяемый слой), драматургию придумаем позже.

## 3. Колода и личный код
- Вариант **А — «колода нашей жизни»**: порядок 12 карт у человека случайно перемешивается **один раз, когда он получает код**; дальше каждый день он нажимает любую закрытую карту и получает следующую по своему порядку (что нажал — на результат не влияет; она это знает и выбрала сознательно). Сервер не нужен, всё считается из кода на любом устройстве. Пропущенный день: карта этого дня «уходит» сама в 00:00, карт всегда столько, сколько осталось дней.
- Получение кода: Проводник даёт в группе **общий ключ** (для Погружения — свой) → на странице человек вводит ключ → **поворачивается калейдоскоп** → складывается **личный узор** (рисуется из кода, на любом устройстве тот же) и **код буквами** (вида `СОЛНЦЕ-7QX4`) → подсказка «сохрани узор и код и пришли код Проводнику в личные». Сайт помнит код на этом устройстве; на другом — ввести свой код (не ключ). Код определяет формат (journey/immersion).
- Ключ проверяется в браузере, храним не сам ключ, а его отпечаток («замок от дневника»). Ключи меняются в панели на каждую волну.
- Код можно получить **заранее**, до 5 октября (нужно).
- В панели: ввести присланный код → увидеть узор и порядок карт по дням.
- Позже, если захочет настоящий выбор (какую нажал — та и выпала): маленькое хранилище на Beget (только «код → карты»), без смены кодов. Supabase не берём. Запись следа текстом на сайте — нет (только Telegram).
