# Запись клиентов на встречи (решения 28.10.2026)

Обсуждали в чате «💬 13M · Витрина · 28.10 · запись к Host и оплата»; план записан и шаг 1 (проба) сделан в чате «13M · Витрина · 28.10 · запись клиентов: проба окошка».

## Как это видит человек
1. Открывает на витрине карточку «Индивидуальная работа» (постоянная), на ней плашки: индивидуальная встреча, шаманская работа на колесе, регрессионная сессия, расстановки.
2. Нажимает «Записаться» на плашке → окошко с календарём: подсвечены дни, где есть свободное время.
3. Выбирает день → время. Свободное время считается само по длительности встречи (регрессии нужно окно 3 часа, встрече — полтора).
4. Выбирает «онлайн / очно» (адрес или ссылку она присылает сама в переписке; кабинеты могут быть разные).
5. Перед оплатой строка: «Отменить или перенести можно не позднее чем за 12 часов — напишите мне».
6. Внизу окошка — «Задать вопрос» (открывает «Куда написать?», как сейчас).
7. «Оплатить» → ЮKassa. Пока человек платит, время держится за ним ~15 минут; не оплатил — время снова свободно.
8. После оплаты: «Вы записаны: регрессионная сессия, пт 31.10, 15:00 (Мск)», кнопка «Добавить в мой календарь» (напоминание у него в телефоне) и «Чтобы я могла с вами связаться, напишите мне, пожалуйста» — Telegram / VK с готовым текстом «Я записан(а) на …». Чек присылать не обязательно (ЮKassa сама сообщает «оплачено»); если не написал — запись всё равно действует.
- Время везде **по Москве**: «15:00 (Мск)».

## Что хранится на сервере
Только занятое время и вид встречи: «пт 31.10, 15:00–18:00 · регрессионная сессия · очно · оплачено». **Ни имени, ни телефона, ни кода.**
⚠️ Анонимность (предупредили её): данные человека (карта, почта/телефон для чека) видит только ЮKassa — это обязательная часть любой оплаты, обойти нельзя; наш сайт их не видит. Страницу «Конфиденциальность» дополнить: запись хранит только занятое время, оплата — через ЮKassa.

## Что настраивает она (панель, раздел «Запись»)
- Часы работы по дням недели, выходные и отпуск, перерыв между встречами.
- «Записаться можно не позже чем за N часов» (её: настраивается, как в RubyTime), «Открывать запись на N дней вперёд», «Отмена — не позднее чем за N часов» (сейчас 12).
- Список записей и кнопка «Освободить время».
- У каждой плашки: «Запись по календарю: вкл/выкл» и «Длительность записи, минут» (сейчас: встреча 90, шаманская 60, расстановки 60, регрессия 180). Цена — с самой плашки. Плашки она скрывает/добавляет сама, как сейчас (шаманская остаётся).

## Календарь

## Защита от накладок
- Список записей хранит **сервер** (не Google): перед показом времени и перед подтверждением оплаты сервер проверяет свой список — двух людей на одно время не будет.
- Связь с Google прервалась → сайт **перестаёт предлагать время** и показывает «Запись временно через сообщение» с кнопкой «Написать»; бот сразу сообщает ей.

## Бот Host
Для самой записи не нужен. Помощник: «Новая запись: …, оплачено», утром «Сегодня у вас: …», тревога при сбое (календарь, ЮKassa); «Задать вопрос» ведёт к нему, как сейчас.

## Её решения 28.10 — вид окна записи (пробу больше не меняем)
- В панели, раздел «Запись», переключатель **«Вид окна записи»**: **«Как у витрины»** (как окно «Куда написать?»: шрифт, кнопки-перелив, блик, контур) / **«Спокойный»** / **«Свой»** (шрифт, вид кнопок — заливка / контур / стекло / перелив, блик вкл/выкл, как отмечать свободные дни — кружок / свечение / жирная цифра). - **По умолчанию — «Спокойный»**, и главное в нём для неё — **шрифт**: тонкий, простой, по-деловому, «не сказочно». **Цифры в календаре — не жирные и без свечения** (ей мешают): свободный день — светлый кружок цвета месяца, выбранный — заливка акцентом. Кнопки — ровная заливка без перелива и блика, контур — тонкая ровная линия. Шрифт с завитками — самое большее в названии встречи (уточнить с ней на шаге 2, когда увидит на сайте).
