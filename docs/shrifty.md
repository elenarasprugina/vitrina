# «Шрифты и надписи» — единый инструмент (её решение 20.11.2026, план; делать в новом чате)

## Почему
Шрифт Cormorant Garamond тонкий; на новом светлом фоне ноября мелкие надписи почти пропали. Настройки шрифта сейчас разбросаны
заплатками: у карточек витрины — «Шрифт», «Размер заголовка» (`titleSize`), «Размер мелких надписей» (`smallSize`), «Размер текста на обороте» (`backSize`);
у Песочницы/Примеров/Событий — «Шрифт», «Размер текста» (`look.textSize`), «Мелкий текст» (`look.smallText`, класс `m13-dense`, сделан 20.11 — **она против такого переключателя**: «что за "как было"»);
у стекла на картинках — свой шрифт и толщина. Её слова: «единый инструмент для всех надписей: шрифт, плотность, толщина…».

## Что она сказала «делаем» (20.11)
1. Весь сайт — в одном тоне: брусничный #960c0d → гранатовый **#7a0a12** (Песочница уже — в черновике; витрина: `accent`, `rimColor`, `btnColor`, `head.shineColor` у карточек ноября).
2. Шапку витрины («13 MIRRORS · ВИТРИНА», «Ноябрь 2026») придвинуть к сетке (сейчас прижата к верху, сетка по центру — в высоком окне большая пустота).
3. Мелкие надписи витрины читаемыми: «МАРШРУТ/ПРОДУКТ», даты, статусы, «завершён/варианты/предзаказ», кнопки «открыть», шапка (кикер сейчас системный шрифт 11px), дни недели в календаре; подпись под отзывом в Песочнице («Сладкоежка · Июль 2026»).
4. Вместо переключателя «Мелкий текст» — единый инструмент (ниже).

## Предложение (ждёт её ответов на вопросы внизу)
Панель → **«Шрифты и надписи»** — одно место для витрины, Песочницы, Примеров, Событий.
Надписи по ролям, у каждой: **шрифт** (свои из `assets/fonts/`: Cormorant Garamond, Lora, Playfair Display, Philosopher, Montserrat, Jost, Comfortaa, Marck Script),
**размер** (ползунок, %), **толщина** (тонкий / обычный / плотный / жирный — только те, что есть у шрифта), **разрядка** (обычная / шире), **цвет** (как у страницы / свой).
Роли:
- **Заголовки** — «Ноябрь 2026», «Как устроены маршруты», названия карточек и маршрутов;
- **Строчки-подписи** — «МАРШРУТ», даты, статусы, «завершён», дни недели, подписи под отзывами;
- **Основной текст** — описания, тексты дней, отзывы;
- **Кнопки** — «открыть», вкладки, фильтры, кнопки на обороте;
- **Надписи на стекле картинок** — «Маршрут · даты», название, «День …».
Рядом — живой образец (как на сайте). Старые поля (`titleSize`, `smallSize`, `backSize`, `look.textSize`, `look.smallText`, шрифт карточек/страниц) переносятся в инструмент один раз (`migrate()`), из карточек и оформления страниц убираются, чтобы не было двух мест.
