# Плашки с картинками, плитки и колесо кина — ТЗ (её решения 19.10, к заходу «делаем» в новом чате)

Проба вида колеса: https://claude.ai/artifact/GisnPmw7NswgcEKRweCPwF · исходник `docs/kin-mini-proba.tpl.html` + `docs/kin-mini-proba.build.py`
(там же — пробные правки `assets/kinwheel.js`: `calm`, `still`, `glint`, `ease`, `twk`, `noText`/`btn`, `tiny` — переносить их в сам `kinwheel.js`).
Сейчас на сайте: плашки (`kind:'items'`, шаблон `offerItem`, `vitrina.js` ~стр. 1597) — без картинок; блок `kind:'kin'` → `kinFormHTML('card')` — маленькое колесо в тёмно-синем квадрате, с кнопкой «Открыть».

## 1. Картинка у каждой плашки
- В панели у каждой плашки — поле «Картинка плашки» (`item.image`, `imageIn` со строкой «📐 Лучший размер»). Без картинки — как сейчас.
- Её примеры: «Шаманская работа на колесе» — бубен; свечи — набор свечей; «Твой уникальный Архетип» — карты (сейчас `media/a890d0b2cae3689c59ab.webp`). Картинки загружает она сама.
- У свечей плашек нет (только `desc`, `dates`, `actions`) — она сама добавит блок «Плашки» («＋ Блок»).

## 2. Вид плашек — выбор у блока «Плашки»
- **Список** (как сейчас) — картинка маленькая слева (как колесо в варианте А пробы).
- **Плитки** — по две в ряд (и на телефоне): сверху картинка, под ней название и коротко цена; вся плитка нажимается.
  - **Нажатие → окошко**: картинка, полный текст, цена, кнопка плашки («Заказать» / «Написать» / событие — то, что настроено у плашки сейчас). Окно — как другие окна витрины, без полосы прокрутки (как `.m13-rvm-box`).
  - **Нечётное число плиток**: выбор у блока «Последняя плитка» — **по центру** (по умолчанию, «само подстраивается») / **во всю ширину**.
  - **Форма картинки на плитке** (её ответа не было — делать выбором у блока): квадрат (по умолчанию) / вытянутая как карта 4:5.

## 3. Колесо кина
- **Колесо как плитка/плашка**: у плашки выбор «Вместо картинки — колесо „Узнать свой кин“» → в плашке маленькое живое колесо (без цифр, `tiny`), нажатие — страница кина на весь экран (`openInternal('kin')`), а не окошко. Так на Карте-Отражении в одном блоке рядом: «Твой уникальный Архетип» (картинка) и «Узнать свой кин» (колесо); местами — стрелками ↑↓.
- **Отдельный блок «Узнать свой кин»** остаётся, выбор вида (её выбор — оставить все):
  - в плашке, колесо **слева** / **справа** (вариант А пробы; текст рядом: «Узнать свой кин» / «по дате рождения · бесплатно» / «Открыть →» — надписи из панели);
  - **рядом с картинкой** (вариант Б: картинка и колесо одной высоты в ряд);
  - **посередине, но меньше** — без цифр на кольцах, без кнопки, надпись «Узнать свой кин» внутри круга, мягко светится (дышит).
  - Медальон у заголовка (В) — **не берём**.
- **Фон колеса** (все три): стекло / без фона (мягкое свечение) / цветной, как сейчас.
- **Движение** (все три): тихое (набирает сегодняшнюю дату и стоит; блик ~6 с раз в ~18 с, мягче; точки мерцают медленно) / совсем тихое (без блика) / неподвижное. Прежнее быстрое («истерика», перескоки на случайную дату) — убрать.
- **Середина колеса**: кнопки «Открыть» нет; надпись мельче и всегда внутри круга (не выходит за него).
- Маленькое колесо (< ~150 px) — без подписей на кольцах: дни и месяцы точками, без значений под стрелкой.

## 4. Панель
- Блок «Плашки»: «Вид: список / плитки», «Последняя плитка: по центру / во всю ширину», «Форма картинки: квадрат / 4:5»; у плашки — «Картинка плашки», «Вместо картинки — колесо кина».
- «Карты-Отражения» → «Узнать свой кин» → «Оборот карточки»: вид (слева / справа / рядом с картинкой / посередине), фон, движение, надписи плашки колеса.
- Старые данные не ломать: без новых полей — как сейчас (список, без картинок); перенос в её черновик — `migrate()` только в пустые поля.
