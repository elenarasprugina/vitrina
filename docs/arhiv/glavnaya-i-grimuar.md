## Гримуар «Калейдоскоп твоих миров» (обсуждается в отдельном чате, ничего не сделано)
**Главный источник — её документ «Гримуар: итоги обсуждения»:** https://claude.ai/code/artifact/aeb047b1-289a-4ffc-827c-b288c7b8b48e (читать через Claude Docs; там же ссылки на эскиз гримуара и бриф для генератора картинок). Решения — только оттуда; здесь кратко, на 30.09.2026:
- **Мир 13 зеркал** (один, сам проект) → **миры людей** (глава = мир одного человека) → **узор**. **Хранитель** невидим, его след — блик (по странице и золотому обрезу при листании; блик на двери мира = «обновлено»). **Проводник** — она сама: одна подпись (фото подписи → золото/сепия, «Проводник 13 MIRRORS») в Летописях и Гримуаре; «слово составителя»; свидетельство в конце мира по галочке.
- **Три части, один механизм калейдоскопа:** книга «Калейдоскоп твоих миров»; практика «Калейдоскоп чувств» («Как ты сейчас?», сила, узор, «Сохранить»/«Отпустить» — огонь, вода, небо, одуванчик; карта чувств по Плутчику, правится в панели); калейдоскоп с МАК-картой (отложено). Общая **библиотека стёклышек** в панели. Практики — отдельный раздел сайта, не в книге.
- **Книга:** адрес 13mirrors.ru/grimoire/, у мира свой адрес (постоянный номер + меняемый красивый адрес); одна растущая книга, тома заложены, но скрыты; миры подгружаются по мере листания; обрез толстеет; последняя страница «Здесь появится следующий мир». Начало: обложка (всё в панели) → калейдоскоп → «О мире Тринадцати Зеркал» → оглавление из дверей → первый мир. Мир: **дверь** (фон-мир + один и тот же калейдоскоп без фона + живой узор из работ в окошке; на компьютере всегда справа) → титул → работы (8 раскладок) → концовка; у мира своя рамка («семья деталей»).
- **Поиск «Найти след»** (ленточка-закладка + поле в оглавлении), скрытые метки (маршрут, сезон, форма, свободные), ничего не отправляет. Летописи и отзывы — **не** в книге.
- **Бережность:** письменное согласие в Telegram (текст напишет Claude), «примерка» мира по ссылке до «да» автора, доступ всем / по ссылке / скрыт, заметка о согласии только для неё.
- Отложено: превью в Telegram, МАК-калейдоскоп, «кинофильм» (отдельно).
