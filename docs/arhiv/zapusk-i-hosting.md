## Пустой файл во время пересылки (исправлено 02.10.2026)
- **Что было:** после влития шага 3 панель в Chrome писала «Не получилось загрузить данные витрины» (в инкогнито и Safari — открывалась). Консоль: `Unexpected end of JSON input` на `data/settings.json`. Причина: пересылка на Beget (`lftp mirror`) переписывала **все** файлы прямо на месте (после свежего checkout у всех файлов новое время); кто открыл сайт в эту минуту, получал пустой/обрезанный файл, а Chrome запомнил его и потом получал «не изменился» (304). Помогло: DevTools → Network → Disable cache → обновить.
- **Исправлено:** `deploy-beget.yml` — `set xfer:use-temp-file yes; set xfer:temp-file-name .up-*`: файл грузится под временным именем и встаёт на место переименованием (проверено на тестовом sftp-сервере: ни мгновения пустого файла, inode меняется; старые `.up-…` удаляет `--delete`). Если сервер не даст переименовать — запасной путь как раньше, с предупреждением в журнале. `getJSON` в `admin.js`, `vitrina.js`, `route.js`: при ошибке/обрезанном JSON — сразу повтор с `cache: 'reload'` (мимо памяти браузера, заодно заменяет испорченную копию), потом ещё 2–3 раза с паузой; 404 — без повторов. Панель пишет «Сайт как раз обновляется — пробуем ещё раз…». Опубликованные страницы месяцев берут данные из `M13_DATA` в самом html — им повтор не нужен.
