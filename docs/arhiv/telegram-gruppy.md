# Архив · Группы Telegram для маршрутов (обсуждение 03–04.10.2026, кода нет)

_Сводка двух чатов: «20 групп Telegram» (ветка `claude/great-bardeen-6stvo5`) и «20 групп Telegram: порядок действий» (ветка `claude/zen-babbage-37sq1x`). В тех ветках — только записи в прежнем `status.md`; вливать их **не нужно**, всё главное — здесь. Что действует сейчас — `docs/karta.md`._

## Задача
20 волн Цолькина = 20 маршрутов. У каждой волны — своя **закрытая группа Telegram с темами** («живое групповое поле»: участники выкладывают материал и общаются; канал не подходит). Группа одна навсегда: та же волна возвращается через 260 дней с теми же 13 кинами. Сейчас у маршрута одна ссылка — `journeys.items[].trace.journey` («Оставить след»).

## Анонимность — она предупреждена и выбрала осознанно
В группе участники видят имена, аватары и сообщения друг друга; анонимность кода здесь не сохраняется.

## Что умеет Telegram
- Бот **не может** создать группу и включить «Темы» — это она руками (~2 мин на группу: название, фото, описание — свои у каждой группы; «Темы» вкл.; бот в админы с правами «Управление темами», «Закрепление», «Удаление сообщений»).
- Бот в группе **может**: создать тему (`createForumTopic`), написать и закрепить сообщение, закрыть/открыть тему (`closeForumTopic`), удалить тему со всеми сообщениями (`deleteForumTopic`), скрыть «Общее» (`hideGeneralForumTopic` + `closeGeneralForumTopic`).
- Бот **не видит** список участников; старые сообщения поштучно удалить не может (предел 48 ч).
- Из среды Claude `api.telegram.org` закрыт — проверить запросы можно только у неё.

## Её решения (03–04.10)
- Темы «1 Магнитный», «2 Лунный» … «13 Космический» (как `days[].tone`), одинаковые во всех группах.
- Тема дня открывается **в 00:00 по Москве**; вчерашняя **закрывается** (дописывать нельзя).
- Закреплённое сообщение **своё в каждой теме**: по тексту на кин (20 × 13 = 260), каждый поток те же.
- После потока материалы удаляются; **старых участников убирают**; группа **закрытая**, участников добавляет она; тема «Общее» — **скрыть**.

## Предложено (ждёт её «да»)
- Тему дня бот **создаёт в 00:00**, а не открывает заготовленную: закрытые темы видны участникам вместе с закреплённым текстом, будущие дни были бы видны заранее. Новые темы Telegram ставит сверху — сегодняшний день первым.
- Помощник по расписанию — **GitHub Actions** (как `deploy-beget.yml`): ключ бота она кладёт в Secrets репозитория сама (`TELEGRAM_BOT_TOKEN`, нам не присылает). Запуск в 23:40 МСК, ждёт до 00:00:00; запасной запуск в 00:30. Каждую ночь: какая группа в каком дне → закрыть вчерашнюю тему → создать «N Тон» → написать и закрепить текст кина. День 1 — сначала удалить темы прошлого потока, спрятать «Общее». Утро после дня 13 — закрыть тему 13.
- Кнопка в панели «Проверить сейчас» (запуск Actions её ключом GitHub) — проба на тестовой группе.
- Ссылка-приглашение **по заявке** (своих пускает сразу, чужие — заявка, она одобряет) — её же ставить в «Оставить след». Старых участников она удаляет руками. Бот, запоминающий, кто вступил, — **не берём** (хранить номера аккаунтов = персональные данные).
- Панель: раздел «Группы Telegram» — 20 волн (группа, ссылка, дата начала), 13 названий тем, 260 закреплённых текстов (по кину), когда удалять материалы.
- Порядок по «делаем»: 1) она: бот у @BotFather → ключ в Secrets, одна тестовая группа; 2) мы: помощник Actions + раздел в панели, проба; 3) она: 20 групп (можно постепенно, к началу каждой волны); 4) тексты кинов — по мере готовности.

## Ждёт от неё
