## 11. Шаг 3 сделан (02.10.2026): ключ → калейдоскоп → код, колода, выбор карты-разрешения, личная карта
**Вход.** `?mode=journey|immersion` без кода на этом устройстве → слой «Ключ к маршруту» (не закрывается щелчком мимо): медленно вращается общий калейдоскоп маршрута, поле «Ключ или ваш код», «Повернуть калейдоскоп», ссылка «Пока просто смотреть — Наблюдение» (→ `?mode=observation`). Подошёл ключ (или введён свой код) → калейдоскоп поворачивается (2,8 с, старый узор рассыпается, личный складывается) → «Ваш личный узор», **код**, «Сохранить узор» (PNG 1080 × 1350: узор, формат, код; на телефоне — «Поделиться», имя файла латиницей), «Скопировать код», «Отправить код Проводнику» (копирует код и открывает `route.guide`, пусто → `trace.immersion`), «Войти на спираль». Неверный ключ — `texts.keyBad`, слой вздрагивает. Код можно получить и до 5 октября. Без `?mode=` и с кодом — формат кода; `?mode=observation` — всегда Наблюдение.
**Код** (`route.js`: `makeCode`, `readCode`, `newCode`): слово из 16 (СОЛНЦЕ, ЛУЧ, ЗАРЯ, СВЕТ, ИСКРА, ПЛАМЯ, ЯНТАРЬ, ЗОЛОТО, РАССВЕТ, ПОЛДЕНЬ, ВОСХОД, ОГОНЬ, КОЛОС, ЖАР, СИЯНИЕ, ТЕПЛО) + «-» + 4 знака из `АБВГДЕЖИКЛМНПРСТУФХЦШЭЮЯ23456789` = 24 бита: seed (16, случайный, `crypto.getRandomValues`) · формат (1 бит, Погружение) · проверка (7 бит, `h32('m13code|id|start|mode|seed')`). Ввод прощает регистр, пробелы/дефис, латинских двойников (C, O, X…), ё/й, З вместо 3; опечатку ловит в ~99,5 % случаев. Код **привязан к id маршрута и первому дню** (`start`): поменять `start` после выдачи — старые коды перестанут подходить. Ключ менять можно: коды от ключа не зависят. Ключ проверяется так же, как считает панель: SHA-1 от `m13|<id>|<ключ без пробелов, строчными, ё→е>` (`crypto.subtle`, без https — свой `sha1js`).
**Хранение на устройстве** (`localStorage`): код — `m13ys-code-<id>-<start>`; перевёрнутые дни — `m13ys-<id>-<start>-pick-<код>`; открытые кирпичи — как раньше.
**Колода** (`deckOf`, `permFor`): порядок `permissions` перемешан Фишером–Йетсом от `h32('m13deck|id|start|mode|seed')`; день d → `permissions[deck[d−1]]`. Что нажали в круге — не важно (вариант А). Порядок карт в панели после выдачи кодов не менять (подсказка там есть).
**Узор** (`Kaleido`, `kalParts`, `kalFrame`): из `h32('m13kal|<код>')` — 6/8/10/12 зеркал, 9–13 стёклышек (круг, лепесток, ромб, треугольник, кольцо, луч) в секторе, два цвета-акцента к солнечным, бусины на кольце; холст 2D, сектор отражается по кругу. Одинаков на любом устройстве и в панели.
**Выбор карты** (`openFan`): кнопка-спираль на Карте дня (Путешествие/Погружение, дни 1–12): нет кода → вход по ключу; карта сегодня уже перевёрнута → сразу та же личная карта; иначе — круг: закрытых карт `13 − день` лучами (вылетают из центра по очереди), в 12-й день одна — в середине, крупнее. Нажал → карта выходит в центр и переворачивается (выбор записан) → «Ваше разрешение на сегодня» → «Открыть» → личная карта (как в шаге 1, «Оставить след» по формату). Рубашка — `cardBack` или золотое солнышко-заглушка; лицо — `perm.image` или надпись прописными.
**«Мой код»** — кнопка справа сверху на спирали (Путешествие/Погружение; без кода — «Ввести ключ»): узор, код, те же кнопки, «Ввести другой код» (с вопросом — забыть код на этом устройстве).
**Надписи** (`texts`, все с запасным текстом в коде): `keyTitle keyLead keyPh keyGo keyNote keyObserve keyBad codeTitle codeLabel codeNote save copy copied send sendNote enter myCode myCodeBtn keyBtn codeOther codeOtherAsk toSpiral chooseSmall choose chooseNote chosen open`. `texts.next` (заглушка шага 1) убран. Новое поле маршрута: `guide` — куда присылать код.
**Панель:** «Основное» → «Ключи…» (пояснение, предупреждение об одинаковых ключах, поле «Куда присылать код»), блоки «Вход по ключу, узор и код — надписи», «Выбор карты-разрешения — надписи»; вкладка **«Код участника»** (`jCodes`): ввести код → узор, формат, карта по каждому дню 1–12; «Новый код для проверки — Путешествие/Погружение». «Карты-разрешения»: подсказка не переставлять карты после выдачи кодов.
**Режим проверки** `?debug=1`, раздел «Код и колода»: текущий код и перевёрнутые дни, «Код Путешествия» / «Код Погружения» (тестовый код на это устройство), «Ввод ключа», «Забыть код»; в картах — «Карта — по коду (колода)», кнопка «Выбор карты (круг)» (для выбранного дня, снова закрывает его карту). «Сброс» теперь закрывает и перевёрнутые карты. В адресе: `?card=fan&day=N` (круг, если есть код), `?card=personal&day=N` без `perm` — карта по коду.
**Ключей на сайте пока нет** (`keys` пустые): она задаёт их в панели и публикует; до этого войти можно только по коду из «Проверки» / «Кода участника».
**Дальше:** финал Солнца (драматургия), картинки (рубашка, дни, образец калейдоскопа — по желанию), плашки на обороте карточки «Жёлтое Солнце» (Путешествие → `routes/yellow-sun/?mode=journey`, Погружение → `?mode=immersion`, Наблюдение → `?mode=observation`).

## 16. Шаг 2 по п. 14 сделан (ветка `claude/awesome-gauss-st4ic7`): стёклышки дней, слово-подарок, настройки вида стёклышек
**Её решения (02.10):** стёклышко дня кладётся в узор само, когда день наступил (у всех, пропуск не важен); в Путешествии/Погружении после личной карты — один раз за день показ «Стёклышко дня N легло в ваш узор». Проба для неё: https://claude.ai/artifact/PaucAawocstrdWnd7drfmQ (стёклышки и узор, данные-пример).
**Камни** (`assets/kaleido.js`, раздел «Камни»): вид `look = {kind, cut, shine, clear, size, img}`; `kind`: `gem` (гранёный; `cut`: round, oval, rect, drop, marquise, tri, hex), `cabochon`, `pearl` (перламутровые отливы), `bead` (бусина с отверстием, вид сверху), `crystal` (горный хрусталь: призма с острием), `glass` (плоское витражное стекло в золотой оправе, по `cut`), `image` (своя картинка, PNG с прозрачным фоном; грузится один раз, узор перерисовывается сам). `shine` — блик и искорки, % (0…150); `clear` — прозрачность, % (0…70, по умолчанию 8 = прежние 0,92); `size` — размер в узоре, % (50…200). Стёклышко в `ex.glass`: `{c, look}` (старое `{c, sh}` читается). Новое API: `M13K.stone(canvas, rgb, look, px)` — один камень крупно; `M13K.preload(srcs, done)`; `M13K.lookOf`.
**Данные** `route.glass = {states, days, gifts: {axis, spoke, rim, underside}}` (заготовка в `data/journeys.json`: состояния — кабошоны, дни — прямоугольные самоцветы, ось — круглый, спица — кристалл 110 %, обод — треугольник, изнанка — шестигранник). `color` пусто — «само»: день — `days[i].glowColor` → цвет печати; подарок — оттенок дня (ось светлее на 62 %, спица на 30 %, обод как день, изнанка дымчатая `#807692`-подобная). Вид в коды не зашит — менять можно в любой момент. `migrate`: нет `glass` в черновике → с сайта.
**Узор** (`route.js`): `kalEx(route, c, {days, gifts})` — состояния + стёклышки дней 1…days + подарки; на странице `myEx(c)` = дни по дате (`glassDaysOf(route, curDay())`, максимум 12; режим проверки `sim` учитывается) + подарки этого устройства. Используется во входе, «Мой код», «Сохранить узор» (картинки камней грузятся заранее).
**Стёклышко дня** (`openGlass`): кнопка-спираль на личной карте, день ≤ сегодня, ещё не показан → слой: «День N · кин», «Стёклышко дня N легло в ваш узор», узор без него → камень крупно (`dropGlass`, `.ys-drop`) → уменьшается в центр → калейдоскоп поворачивается с ним → «На спираль». Показанные дни — `localStorage` `m13ys-<id>-<start>-glass-<код>`.
**Слово-подарок** (`makeGift`/`readGift`): `ДАР-` + 4 знака из `CODE_ABC` = 20 бит: (день − 1) × 4 + зона (6 бит, зоны: ось, спица, обод, изнанка) · проверка 14 бит `h32('m13gift|id|start|код|p')`; всё XOR маской `h32('m13giftmask|id|start|код')`. Подходит только к своему коду (чужой примет с вероятностью ~1/16 000); одно и то же (код, день, зона) — всегда одно слово. Ввод прощает регистр, «ДАР», дефис, латиницу, З/3. На сайте: «Мой код» → «Получили стёклышко? Ввести слово» → поле → камень крупно → поворот; повтор — «уже в узоре». Хранится `m13ys-<id>-<start>-gift-<код>` = `[[день, зона], …]`. Ссылка `…/routes/yellow-sun/?gift=ДАР-XXXX` сразу открывает «Мой код» и вписывает слово (без кода — подсказка `texts.giftNeed`). Подарок за любой день 1–12 появляется сразу.
**Надписи** (`texts`, с запасными в коде): `glassSmall glassDay glassNote glassGo giftBtn giftLead giftPh giftGo giftOk giftBad giftHave giftNeed`.
**Панель:** вкладка **«Стёклышки»** (`jGlass`): живой пример узора (сколько дней прошло, с подарками), предупреждение, если стиль «А · Витраж-роза» (там камней не видно); блоки «Состояния», «Стёклышки дней 1–12», «Подарок · Ось/Спица/Обод/Изнанка»: вид, огранка, своя картинка, цвет (пусто — само), блик, прозрачность, размер + образцы камней справа; надписи. **«Код участника»**: узор на сегодня (со стёклышками наступивших дней), блок «Подарить стёклышко» (день, зона → слово, «Скопировать слово», «Скопировать ссылку со словом», камень).
**Режим проверки:** «Стёклышко дня» (для выбранного дня), «Подарок (тест)» (слово за выбранный день, случайная зона → «Мой код»); «Сброс» и «Забыть код» стирают и подарки, и показанные стёклышки.

**Её просьба:** «посмотри узор калейдоскопа — мандала; мы говорили о тонких линиях на калейдоскопе в финале, давай повторим и здесь». Прежняя мандала — плотная эмаль на светлом круге с сепией (тот «поднос», который в финале заменили филигранью).
**Сделано:** у стиля `'mandala'` (`M13K`) новый вид по умолчанию — **тонкие золотые линии на прозрачном фоне**, цвет стёклышек только подкрашивает лепестки (подкраска 8–25 %), линия — золото с бликом посередине (как у филиграни `M13S`, толщина `.0034·rad` × ползунок); светлого круга, тени к краю и света из середины нет; блики по лепесткам, раскрытие, поворот — как были. Прежний вид — «Эмаль на светлом круге» — остался выбором. Узор (кольца, лепестки) — тот же, коды не меняются.
**Данные:** `route.kaleido.mandala` — '' / `fine` (тонкие линии, по умолчанию) | `enamel`; `route.kaleido.line` — толщина линий, % (40–220, по умолчанию 100); `route.kaleido.back` — лёгкое напыление под линиями (по умолчанию нет). `route.js` → `kalLook(route)` → `M13K.Kaleido(…, { look })`, `M13K.still(…, look)`, у живого калейдоскопа `kal.look(o)`; вид лежит на узоре `P.look` (`mandalaDraw`).
