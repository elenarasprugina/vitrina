## Как устроено — главное
- **Публикация** — только она, кнопкой в панели: черновик чистится (`cleanDeep`: без `show:false`, `visible:false`, полей `_…`), картинки `data:` → `media/<хеш>`, собираются страницы с данными внутри (`window.M13_DATA`) и превью для Telegram, всё одним коммитом в `vitrina` → пересылка на Beget.
- **Влили ветку с кодом витрины → один раз «Опубликовать»**: готовые страницы держат код по `?v=`. У страницы маршрута номер версии — `window.M13RV` в `routes/yellow-sun/index.html` (сейчас `20261003j`), **менять при каждой правке** `route.js / route.css / kaleido.js / sun.js`.
- **Перенос в черновик** — `migrate()` в `admin.js` при открытии панели: новое берётся с сайта только в пустые поля / заготовки / прежние написания (одноразовые флаги вида `deck.diskTexts`, `r._evening`); её правки не трогаются. Уходит в GitHub при её «Сохранить».
- **Карточка витрины:** лицо `front` (+ `front.style`, метки по датам `front.phase`), оборот из блоков `back = {type:'blocks', blocks:[…]}`; оформление месяца `showcase.cardStyle`, шапка `showcase.head`, фон `showcase.background`; календарь — `card.monthCal`; обложка при открытии — `cardStyle.lid` / `front.style.lid`.
- **Панель:** группы свёрнуты сами (`foldWrap`), у каждой картинки строка «📐 Лучший размер» (`imageIn(…, {size})` — источник правды о размерах; новое поле с картинкой — сразу с `size`), живой предпросмотр тем же рендерером.
- **Хостинг:** Beget, кабинет `evraspyn`, **тестовый период до ~31.10 — оплатить**. DNS на reg.ru: A `@` и `www` → `87.236.16.38`. Сертификат Let's Encrypt до 30.12.2026, продлевает Beget; http → https включён. После выдачи SSL Beget может сменить IP — сверять «DNS → Текст зоны». GitHub Pages — запасной: вернуть четыре A-записи GitHub — и сайт снова там.
- **Проверка:** витрина — `window.M13_TODAY = 'ГГГГ-ММ-ДД'` до загрузки `vitrina.js`; маршрут — `?debug=1`; в Playwright шрифты Google блокировать (иначе страница «застревает»); из среды Claude 13mirrors.ru и Beget закрыты — сервер проверяет `check-beget.yml`.

## Её правила (кроме CLAUDE.md)
- Везде, где есть цвет, — его можно выбрать в панели.
- Стиль: не мультяшно, тонко, «эльфийское»; в каждый момент движется что-то одно; мигание медленное — проявилось и ушло.

- Название «Нити» не использовать (было до Гримуара).
