# Оформление карточки: контур, блик, узор, фон за открытой (26.10)

Её просьба 26.10: «брусничный лёд» — ягода в ледяной корке, прозрачная, как леденец (образец — груша-леденец с упаковки чая); контур чётче, толщина регулируется и местами толще; своя картинка (ягоды) в одном уголке, меньше; увеличенная карточка на светлой витрине не должна быть серой.

## Поля (`showcase.cardStyle` — для всех карточек, `card.front.style` — своё у карточки; `inherit`/пусто — как у всех)
| Поле | Значения | Где в коде |
|---|---|---|
| `rim` | `light` `cold` `gold` **`candy`** (леденец, сам — брусничный `#b8183c`) | `.m13-rim--candy` в `vitrina.css` |
| `rimColor` | `#rrggbb` — теперь ставится на саму линию (`style="--m13-rc"` у `.m13-rim`); раньше класс вида перебивал его | `decoHTML` |
| `rimWidth` | 0,5–8 px; пусто — 1,3 | `--m13-rw` |
| `rimShape` | `none` `corners` `diag` `bottom` `top` — второй слой в 2,6 раза толще, виден только в зоне (`.m13-rim-zone--*`, маска) | `RIM_SHAPES` |
| `sheen` | 0–100 — «Блик леденца на стекле»: косой блик + цвет снизу (`rimColor`, у леденца — брусника, иначе акцент). Слой `.m13-candy` (не путать с `.m13-sheen` — приветственный блик) | `decoHTML` |
| `veil` | `dark` (как было) `light` `clear` — класс `m13-veil--*` у `#m13-overlay` в `openCard`; при `light` значки ✕ ↺ — тёмный оттенок (`iconVars`). В панели — только у всего месяца | `openCard`, `iconVars` |
| `patternPlace` | + `tl` `tr` `bl` `br` (один уголок, `.m13-pat--one .m13-pat--at-*`), `diag` (2 угла) | `PAT_ONE` |
| `patternSize` | 0–90 — % ширины карточки (0 — прежние размеры) | `--m13-psz`, `.m13-pat--sz` |
| `patternTilt` | −45…45° | `--m13-ptl` |
| `patternMirror` | `mirror` (как было) / `same` — не отражать в других углах | `.m13-pat--same` |
| `patternShadow` | `none` / `soft` — drop-shadow | `.m13-pat--shadow` |

Своя картинка узора теперь `background-size: contain` (раньше 100 % 100 % — растягивалась), прижата к своему углу. Готовые узоры в одном углу отражаются к нему сами; своя картинка в одном углу — как есть.
Готовые узоры: путь через `media('assets/patterns/…')` — url() в CSS-переменной считается от `vitrina.css`; на главном адресе (`data-base="./"`) раньше выходило `assets/assets/…`.
Новые ключи добавлены в `STYLE_FRONT` (копирование оформления) и в сброс «Светлая тема».

## Значки ✕ и ↺ (27.10)
`cardStyle.iconColor` — свой цвет значков во всех окнах (`--m13-ixc`/`--m13-ixl` на `S.root` в `xLook`, и первым в `iconVars`); `cardStyle.iconGlow: 'none'` — класс `m13-ic-flat` у корня: без box-shadow, text-shadow и drop-shadow. ↺ — `UNFLIP_SVG` (тонкая линия, как X_MARK).
`cardStyle.iconSize` (27.10 (2)) — размер знака ✕/↺: `''` — меньше (класс `m13-ic-md`, scale .78; теперь обычно), `'sm'` — совсем маленькие (`m13-ic-sm`, .62), `'lg'` — как было до 27.10. Масштабируется только знак, кнопка того же размера.
Кнопка «Как устроены маршруты» на обороте — `m13-soft m13-action`: слушается «Кнопок на обороте» (остальные кнопки: рамка цветом `btnOtherColor` или как главная). Градиентные кнопки — `background-origin:border-box` (раньше по краям был штрих: градиент повторялся под прозрачной рамкой).
Леденец (`.m13-rim--candy`): градиент без чистого белого — блики светлыми оттенками цвета, конец справа снизу тёмный.

## Кнопка «открыть» и блик-россыпь (27.10 (3))
- `cardStyle` / `front.style` (у карточки можно «Как у всей витрины»): `ctaLook` — вид «открыть» и «Нажать — открыть оборот»: `''`/`'none'` как было (рамка) | `pale` тонкая бледная | `glass` стёклышко без рамки | `word` только слово | `fill` заливка; `ctaColor` — цвет рамки и надписи (у заливки — фон, надпись подбирается: `--m13-cta-ink`); `ctaShadow: 'off'` — без тени (класс `m13-cta-flat`). Классы `m13-cta-*` ставит `styleOf`, стили — в конце `vitrina.css`.
- `head.sheenKind`: `dust` — теперь «Звёздная россыпь» (звёздочки-искры SVG-маской на `::before`, две плитки разного шага, светятся); новый `motes` — «Частицы света» (много крошечных мягких точек).
