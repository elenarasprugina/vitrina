# Бриф для разработки · Витрина 13 MIRRORS

Итог согласования архитектуры. Дополняет и уточняет исходное ТЗ; где они расходятся, действует бриф. Архитектура согласована — не обсуждать заново, а собирать.

## 0. С кем работаем
- Автор проекта 13 MIRRORS, психолог, **не программист**. Живёт в России.
- Объяснять простым языком, без жаргона. Всё, что нужно сделать руками (GitHub, ключ, настройки), — пошагово: куда нажать, что вставить.
- Она никогда не редактирует код. Всё содержимое меняется через панель управления.

## 1. Что строим
Ежемесячная витрина: сетка 3×3 из 9 карточек (маршруты, встречи, продукты) + общая Песочница + страница примеров Карт-Отражений + панель управления. Всё содержимое — данные (JSON), а не код. Октябрь 2026 — первая витрина, код к октябрю не привязан.

Прототип v8 — эталон UX и геометрии: сетка 3×3 (карточки ≈ 9:10, на телефоне блок чуть выше центра), «нажатие → карточка увеличивается лицом → нажатие → переворот → крестик», окно внешней ссылки, внутренние страницы с «← Назад к карте». Мобильный сценарий главный. Оборот на телефоне по возможности без прокрутки.

## 2. Хостинг, домен, репозитории
GitHub Pages, аккаунт `elenarasprugina`, домен `13mirrors.ru` (REG.RU), привязан к главному репозиторию; остальные Pages-репозитории открываются по `13mirrors.ru/<репозиторий>/`.

Адреса: `/vitrina/` — текущая витрина (settings.currentShowcase); `/vitrina/2026-10/` — постоянный адрес месяца; `/vitrina/2026-10/#sun` — открытая карточка; `/vitrina/sandbox/` (#days, #chronicles, #reviews, #reviews/<id>); `/vitrina/reflection/`; `/vitrina/admin/`.

## 3. Данные
`data/settings.json`, `routes.json`, `formats.json`, `showcases/index.json`, `showcases/<YYYY-MM>.json`, `sandbox.json`, `reflection.json`, `media/…`. В `13mirrors-content` — черновики той же структуры; в `vitrina` — только опубликованное и очищенное.

**Никаких персональных данных**: ни скриншотов переписок, ни исходных текстов отзывов, ни контактов посетителей.

- Необязательное поле: `{ "value": "…", "show": true }`; при `show:false` элемент не выводится.
- Действие: `{kind:"contact", label, telegram?, vk?, message?}` → окно «Куда написать? Telegram | VK», текст обращения из шаблона, копируется в буфер; `{kind:"link", label, url}` → сразу открывает адрес. Никаких форм и аналитики.
- Коллекция: элементы с `id`, `order`, `visible`, лимит `max`; кнопка «+ Добавить».
- Маршрут (`routes.json`): id, title, dates{from,to}, kin{value,show}, description, image, routeUrl. Переиспользуется в разных месяцах.
- Карточка: id, visible, interactive, front{image, eyebrow, title, subtitle, status, foot, style}, back{type,…}. Скрытая карточка — нейтральная пустая клетка, сетка не сжимается.
- **Обновлено 27.09:** оборот собирается из блоков, которые включаются и двигаются стрелками (см. `docs/arhiv/vitrina.md`, «Универсальная карточка»); прежние типы ниже стали заготовками.
- Типы оборота: `static`, `route` (форматы с доступностью open/closed и переопределением цены, кнопка «Пройти маршрут», счётчик дня, кнопка в Песочницу), `container` (плашки до 10), `offer` (описание, картинки, цена, плашки-варианты, даты с подписью, состав, кнопка «Примеры», 1–2 действия), `text`.
- Состояния маршрута задаются вручную; формулировки статуса мягкие.

## 4. Панель управления (`/admin/`)
Разделы: Витрины · Маршруты · Песочница · Карты-Отражения · Настройки. Новый месяц на основе предыдущего (списки с `copyItems:false` очищаются). Сетка 3×3 + форма карточки. Переключатели видимости, порядок стрелками. Картинки сжимаются в браузере (WebP). Кнопки: Сохранить · Посмотреть · Опубликовать. Интерфейс по-русски, ошибки человеческими словами.

## 5. Вход и ключ
Fine-grained PAT: только `vitrina` и `13mirrors-content`; Contents: Read and write, Metadata: Read-only, остальное No access; срок 90 дней. Токен не в коде, только `sessionStorage`. Pages в `vitrina` — Deploy from branch.

## 6. Публикация
1. Панель читает JSON из `13mirrors-content` (GitHub REST API). 2. «Сохранить» → коммит в `13mirrors-content`. 3. «Посмотреть» — тем же рендерером. 4. «Опубликовать» → очистка в браузере: убрать поля `show:false`, выключенные элементы, содержимое скрытых карточек, служебные поля (`_backs` и т. п.), в index.json только опубликованные; картинки `data:` превратить в файлы `media/…`, взять только используемые. 5. Запись в `vitrina` одним коммитом (Git Data API: blobs → tree → commit → update ref). 6. «Опубликовано, сайт обновится в течение пары минут».

## 7. Сознательно НЕ делаем
Регистрация, аккаунты, формы заявок, хранение контактов, база клиентов, оплата на сайте, аналитика кликов, публичные ссылки на конференции, CRM.
