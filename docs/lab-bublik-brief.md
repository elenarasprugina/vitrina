# Бриф: бублик Цолькина «волна — виток» для Лаборатории 13 MIRRORS (03.11.2026)

## Что это
На сайте, на странице «Свой кин» (`13mirrors.ru/vitrina/kin/`), после сейфа-колеса открывается механизм: шестерёнки (13 тонов × 20 печатей) и 3D-бублик из 260 точек-кинов, который раскладывается в таблицу («Объём · Таблица · Полотно»). Участник видит только **точный бублик** (`knot`).

В пробе 21.10 было три формы, две на сайт не взяли (решение владелицы):
- **«Волна — виток» (`coil`)** — второй бублик. Дни идут по кругу подряд, каждая волна из 13 дней — один виток вокруг трубки; за 260 дней — 20 витков. **Его и хотим в Лаборатории.**
- «Башня» (`tower`) — 20 витков по 13 снизу вверх (не бублик; по желанию — тоже в Лабораторию).

Точный бублик: печать = место по большому кругу (20), тон = место вокруг трубки (13), путь замыкается через 260 дней.

## Где взять готовое (репозиторий `elenarasprugina/vitrina`)
- `assets/kinmech.js` — механизм сайта (ES5, canvas, без библиотек, своя перспектива). Формы: `coilPos(i)`, `towerPos(i)`, `knotU(i,…)`, `form3d(form, i)`; камера `PITCH = { knot: .55, coil: .62, tower: .22 }`. Вход: `window.M13KINM.mount(элемент, { T, today, cfg, waveTitle })`; `cfg.form = 'coil'` уже работает.
- `assets/kin.js` — счёт кина по дате (Dreamspell, 29 февраля — Хунаб Ку, не считается).
- Пробы с переключателем всех трёх форм: «Цолькин в объёме» https://claude.ai/artifact/RvaiBxZubqmrYmxAeMeTkv (`docs/tzolkin-3d-proba.tpl.html` + `.build.py`) и «сейф → механизм» https://claude.ai/artifact/Sn3N46EHwhWhaW6Zes76Pd (`docs/tzolkin-mech-proba.tpl.html` + `.build.py`).
- История решений — `docs/tzolkin-gears.md` (разговоры 2–5).

Формула витка (из `kinmech.js`), i = 0…259:
```
ph = i/260·2π;  th = (i % 13)/13·2π − π/2;  r = 0.36
x = (1 + r·cos th)·sin ph;  y = r·sin th;  z = (1 + r·cos th)·cos ph
```

## Что уже умеет (можно взять в Лабораторию)
- Вращение пальцем/мышью с инерцией, приближение, медленное самовращение (кроме «меньше движения»).
- Дальние точки мельче и тусклее, тонкие кольца-направляющие (у витка — 13).
- Подсветка: волна сегодня / все дни печати / тона / порталы; «сегодня» — звезда; пройденное ярче, впереди тусклое; «▶ Проиграть» (в пробе).
- Цвет: печати / замки (5×52) / сезоны (4×65 с тона 3).
- Нажатие на точку — Kin, название, дата, волна.
- Разложить: таблица / полотно (у витка — плавный переход по `ease`).

## Правила проекта (обязательно)
- Чистые HTML/CSS/JS, ES5, без сборщиков и библиотек; шрифты — свои (`assets/fonts/`), никаких внешних подключений, аналитики, форм.
- Анонимность: дата человека считается только на его устройстве, никуда не отправляется.
- Знаки печатей — дримспеловские (решение её).
- Владелица — не программист: объяснять просто, по-русски; показывать снимками (телефон 390 px, компьютер 1366–1440 px); «обсуждаем»/«стоп» — ничего не менять.
