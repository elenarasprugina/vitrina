## Как устроено (самое нужное)
- **Репозитории:** `vitrina` (публичный, код + опубликованные данные `data/`, картинки `media/`), `13mirrors-content` (закрытый, черновики той же структуры, картинки внутри JSON как `data:`), `elenarasprugina.github.io` (главная). Стек — чистые HTML/CSS/JS, ES5, без сборщиков.
- **Код:** `assets/vitrina.js` + `vitrina.css` (витрина и предпросмотр в панели, `window.M13`), `admin/admin.js` + `admin.css` (панель, `window.M13_ADMIN`), `assets/route.js` + `route.css` (страница маршрута, `window.M13R`), `assets/kaleido.js` (`M13K`, калейдоскоп), `assets/sun.js` (`M13S`, Солнце финала).
- **Данные:** `data/settings.json`, `routes.json` (маршруты для карточек витрины), `formats.json`, `showcases/index.json` + `showcases/ГГГГ-ММ.json`, `sandbox.json`, `reflection.json`, `events.json`, `journeys.json` (страницы маршрутов по дням).
- **Панель:** черновик в браузере (`localStorage m13-admin-draft-v1`) + «Сохранить» (коммит в `13mirrors-content`) + «Опубликовать» (`buildSite` → чистка → картинки в `media/<sha1>` → один коммит в `vitrina`; пересобирает `index.html` страниц витрины с данными внутри — `pageHTML`). Ключ — только `sessionStorage['m13-gh-token']`.
- **Перенос в её черновик:** когда меняем данные на сайте, её черновик догоняет `migrate()` в `admin.js` один раз (флаг) и только в пустые поля/заготовки — её правки не трогать.
- **Номер версии:** правишь `route.js / route.css / kaleido.js / sun.js` — поднять `window.M13RV` в `routes/*/index.html` и `ROUTE_V` в `admin.js` (по нему публикация пишет страницы новых маршрутов); правишь `vitrina.js/css` — `?v=` в страницах витрины меняется только при её публикации.
- **Проверка дат:** витрина — `window.M13_TODAY='ГГГГ-ММ-ДД'`; маршрут — `?debug=1` (выбор дня, финал, сброс, коды).
- **Устойчивость:** `getJSON` повторяет загрузку при обрезанном файле; пересылка на Beget пишет через временные файлы.
